# C++11

| Target | Main idea |
| --- | --- |
| `cpp11_type_deduction` | `auto`, `decltype`, and expression types |
| `cpp11_strong_types` | `nullptr`, scoped enums, typed interfaces |
| `cpp11_initialization` | Braced initialization and initializer lists |
| `cpp11_move_semantics` | Ownership transfer and moved-from objects |
| `cpp11_smart_pointers` | Unique and shared ownership |
| `cpp11_lambdas` | Captures and callable values |
| `cpp11_range_algorithms` | Range-for and algorithms |
| `cpp11_variadic_templates` | Parameter-pack expansion |
| `cpp11_perfect_forwarding` | Forwarding references and value categories |
| `cpp11_constexpr_traits` | Compile-time computation and traits |
| `cpp11_class_controls` | `default`, `delete`, `override`, and `final` |
| `cpp11_concurrency` | Threads, futures, mutexes, and atomics |
| `cpp11_chrono_random` | Durations and deterministic random engines |
