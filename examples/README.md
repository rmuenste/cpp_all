# Language and library examples

The folders follow the standard in which a feature first became available.
Each source is both a short lesson and an executable test. Read the folder
indexes in order, or build any target directly by name.

| Standard | Focus |
| --- | --- |
| [C++11](cpp11/README.md) | Modern language foundations, ownership, concurrency |
| [C++14](cpp14/README.md) | Deduction improvements and compile-time utilities |
| [C++17](cpp17/README.md) | Vocabulary types, compile-time branching, filesystem |
| [C++20](cpp20/README.md) | Concepts, ranges, coroutines, synchronization |
| [C++23](cpp23/README.md) | Safer error handling and incremental language refinements |
