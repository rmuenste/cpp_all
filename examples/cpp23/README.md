# C++23

The baseline lessons cover `if consteval`, static and multidimensional
operators, decay-copy syntax, range-for lifetime extension, `expected`, monadic
`optional`, byte/enum utilities, and span-backed streams. Explicit object
parameters and `expected` are enabled when configure-time compiler/library
probes succeed.

`std::print`, `std::mdspan`, and later range additions are future work because
the baseline standard library does not provide them consistently.
