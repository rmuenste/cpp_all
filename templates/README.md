# Template programming

This track is organized by purpose rather than language version:

1. [Deduction and constraints](deduction/README.md) explains how templates are
   selected and how modern constraints replace older SFINAE techniques.
2. [Compile-time programming](metaprogramming/README.md) builds data structures
   and algorithms over values and types.
3. [Template-based design](design/README.md) applies templates to program
   architecture, composition, customization, and performance.

Older techniques are retained because they explain existing code, but examples
call out the clearer C++20 alternative when one exists.
